## Inspiration

Before a single frame is shot, a producer has to answer a deceptively hard
question: *what is the most practical way to actually film this scene, and what
will it cost?* Today that means days of scattered scouting, spreadsheet
guesswork, and vendor emails — and the numbers that come back are impossible to
trust because you can't see where they came from. We wanted an agentic desk that
turns a scene into a **decision** you can defend, with the evidence and the math
in the open.

## What it does

StudioClear takes a screenplay scene and helps a producer **compare three
practical ways to film it** — a Nearby practical location, an Alternative travel
location, and Local filming + VFX — using real research and transparent,
editable costs.

1. **Understand the scene.** Gemini extracts the scene, preserves creative intent
   (a fantasy "gold-touch" power is kept, not "corrected"), and locks the exact
   dialogue the producer marks.
2. **Research the options.** For each approach, a Parallel-backed agent gathers
   real, cited leads — crew day rates, location/permit conditions, hotel rates,
   incentive context — from live sources.
3. **Cost it honestly.** A deterministic cost engine (Decimal ranges,
   contingency once, shared-expense de-dup) turns the producer's brief into
   low–high estimates. **Unknown prices never become $0** — they surface as
   "Quote needed" and the total is marked *incomplete*, never falsely cheap.
   Incentives are only calculated when eligibility evidence exists.
4. **Change a constraint, recompute.** Adjust crew size or shoot days and
   recalculate — the affected cost lines move by arithmetic, not a new web search,
   and a new versioned comparison is saved with its parent linked.
5. **Decide and hand off.** Select an option "for further planning" (this creates
   **no booking**), then export a sanitized planning brief (scene text, chosen
   option, alternatives, assumptions, unresolved quotes, and every cited source)
   as TXT / printable PDF / JSON a collaborator can act on.

The product is deliberately honest: it recommends "no clear winner" when the cost
ranges overlap rather than inventing a false winner, and it never claims booked
crew, guaranteed incentives, or money saved.

## How we built it

The demoed shoot-comparison flow is: **Gemini extraction → Parallel research →
deterministic cost engine.**

- **Google Cloud + Gemini** (Gemini Developer API via `google-genai`) — scene
  extraction runs on `gemini-2.5-pro`; research normalization on
  `gemini-2.5-flash`. Creative intent and locked dialogue are preserved, not "corrected".
- **Parallel Search API** (partner track) — the live production provider runs real
  Parallel searches for each option's leads. Source URLs are read **verbatim** from
  the Parallel response, never generated by the model.
- **Google ADK 2.8.0** — the optional **Scene-review** path runs three real
  `google.adk` Agents (Planner / Researcher / Reviewer); the Researcher calls
  `parallel_search` as an ADK tool at runtime. This is the fact-checking mode, not
  the shoot-comparison shown in the video.
- **Deterministic core (Python):** `cost_engine.py` (Decimal range math,
  contingency, shared-expense de-dup, unknown→incomplete) and
  `shoot_comparison.py` (three fixed option slots + honest recommendation) — pure
  functions, unit-tested, no LLM-guessed numbers.
- **FastAPI** backend + a single-page vanilla-JS UI (Analyze / Shoot options /
  Scene desk / Handoff). Session-scoped, private by default, 24-hour expiry.
- **Deployed on Google Cloud Run**, keys in Secret Manager, built from source via
  Cloud Build.

## Evidence-integrity invariant (our core credibility rule)

The LLM must **never** emit a `source_url`. URLs pass through verbatim from the
Parallel tool response; a guard (`enforce_grounded_sources`) rejects any model-
authored URL, and an adversarial test proves it. Every number is labeled by its
provenance — *published rate*, *supplier quote*, *producer estimate*, or *unknown*.

## Data sources

- **Parallel Search API** for live production-research leads (crew rates, location
  and permit conditions, accommodation, incentive context).
- **Producer brief** — the producer's own rate assumptions and quotes are the
  source of truth for costs; StudioClear never fabricates a price.
- No third-party copyrighted material, logos, or trademarks are used; the demo
  scene is original content and a fictional brand is used for any negative context.

## Findings & learnings

- **Honest incompleteness beats a confident wrong number.** The hardest and most
  valuable engineering was making "we don't know this price yet" a first-class,
  non-zero state that keeps the total trustworthy.
- **Keep the model out of the math and the citations.** Determinism (costs, policy
  state, confidence are pure functions of inputs) plus verbatim source pass-through
  is what makes the output defensible to a producer.
- **Agents for research, code for judgment.** ADK agents are excellent at gathering
  cited evidence; the decision logic (ranges, recommendation, "no false winner")
  belongs in tested code, not a prompt.

## Verified live run (for your reference — Sep 9, 2026)

A real end-to-end run against the hosted app, to confirm the demo works on camera:

- Scene created live (Gemini extraction, ~10s) — full text + dialogue locks preserved, `task=plan`.
- Three-option comparison (live Parallel, ~11s) — **8 real cited sources**
  (needacrew.com, focal.ch/Portugal, beyondfocus.pt, TripAdvisor Portugal, …).
  - Nearby (LA): **$32,230–$53,350**
  - Travel (Portugal): **$37,620–$63,800**
  - Local + VFX: **$53,475–$108,100**
  - Recommendation: *ranges overlap — no clear winner* (honest, by design).
- Recalc (traveling crew 10 → 18): **only** the Travel option moved
  → **$67,012–$112,640**; the other two unchanged (arithmetic, not re-search).
  New comparison saved as calculation_version 2 with parent linked.
- Selected Travel for planning; handoff brief exported with all 8 sources resolved,
  scene-review status "Not requested".
